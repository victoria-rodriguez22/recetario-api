# Sistema de Menú de Comidas

## Descripción
API sencilla para gestionar un recetario con desayunos, comidas y postres. Permite crear, consultar, editar y eliminar platillos, incluyendo su nivel de dificultad y precio.

## Tecnologías
- Python 3.15
- FastAPI
- SQLModel (SQLite)
- Redis (caché)

## Ejecutar el proyecto

uvicorn main:app --reload
